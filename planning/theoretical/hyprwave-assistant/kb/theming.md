# Theming in Hyprwave

Hyprwave ships with a powerful multi-theme system.

## Available Themes
- Default: Synthwave (Hyprwave classic)
- Retro Arcade
- Cozy Harvest
- Fjord Dark
- Touge Drive
- Vaporwave
- Highway Haze
- Lunar Pulse
- Glitch Horizon
- Arcade Rain
- Verdant Haven (nature)

## How to Switch
(Planned) Use Hyprwave Assistant → Settings → Theme, or the `hyprwave set-theme <name>` command.

Wallpapers, Walker themes, Waybar styles, Ghostty palettes, and greeter themes are all switched together.

## For Theme Authors
Themes live under `/usr/share/hyprwave/themes/`. Each theme provides:
- Hyprland looknfeel
- Ghostty palette
- Waybar CSS
- Walker style
- Mako config
- COSMIC .ron
- SDDM overrides
- Wallpapers

See the theme pack planning for details.
